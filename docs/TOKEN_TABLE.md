# What one Milpa Token redeems for

One token = one hour of work. It redeems for food of the same retail value at
Ernestine's own prices (case Exhibit B). The anchor is **10 lb of corn**
(10 × $0.30 = $3.00). Every other item is set to the same $3.00.

| Item | One token redeems for | Retail value at Tierra Viva | Redeemable in (normal year) |
|---|---|---|---|
| Corn (dried, from sale drum) | 10.0 lb | $3.00 | Jul, Aug, Sep, Oct (pre-harvest and storm months) |
| Beans (dried, from sale drum) | 3.0 lb | $3.00 | Jul, Aug, Sep, Oct |
| Seed corn | 3.0 lb | $3.00 | Apr, Nov (weeks before planting) |
| Plantains (surplus on hand that month) | 12 | $3.00 | Nov, Dec, Jan (harvest) |
| Peppers, tomatoes, herbs (surplus on hand) | 2.0 lb | $3.00 | Nov, Dec, Jan (harvest) |

Regenerate with `milpa token-table` (add `--year bad` for the bad-weather calendar).
